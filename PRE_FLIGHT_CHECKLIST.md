# PP-food-001 Pre-Flight Checklist

在 READY 或任何生产动作前执行。本清单是运行门禁。

## A. Cold-Start Read Status

必须得到：

```text
VERSION_READ = PASS
RUNTIME_MANIFEST_READ = PASS
SKILL_READ = PASS
HANDOFF_READ = PASS
REQUIRED_READ_SET_READ = PASS
COLD_START_CORE_REFERENCES_READ = PASS
RUNTIME_TESTS_READ = PASS
REGRESSION_TESTS_READ = PASS
EXECUTION_CONTRACT_TEMPLATE_READ = PASS
```

任一不是 PASS：

```text
PRODUCTION_GATE = BLOCKED
```

## B. Bootstrap Proof

必须准确确认：默认且最终严格 9:16、默认 A、显式 A 覆盖自动 B、B 必经 Stage A、Food/Geometry/Plating/Physical >=95、Vessel >=98、Hero/Appetite >=85，以及：

```text
OUTPUT_ASPECT_RATIO_EXACT = 9:16
NON_9_16_DELIVERY = CRITICAL_FAILURE
SOURCE_SURFACE_STATE > APPETITE_ENHANCEMENT
TOPOLOGY_PRESERVING_COMPLETION_ONLY = TRUE
BACKGROUND_ARCHITECTURE > PROP_STYLING
PRODUCT_DERIVED_STAGE > GENERIC_PREMIUM_STYLE
HERO_STAGE_OVERRIDES_GENERIC_VENUE_CONTEXT = TRUE
CONTROLLED_HERO_REFRAME_ALLOWED = TRUE
SOURCE_CAMERA_COORDINATES_ARE_FOOD_DNA = FALSE
MULTI_PRODUCT_HERO_HIERARCHY_REQUIRED = TRUE when applicable
```

视觉张力与 Fidelity 冲突时降低危险设计动作，不降低 Fidelity；“更有食欲”不能改变火候、熟度、烘烤深浅、焦化、油亮/湿润等级、酱汁覆盖或表皮结构。

## C. Declared Runtime Capabilities

静态检查：

```text
VISION_MODEL_IMAGE_INPUT = PASS / MISSING / UNKNOWN
VISION_MODEL_CAN_READ_GENERATED_OUTPUT = PASS / MISSING / UNKNOWN
IMAGE_MODEL_REFERENCE_EDIT = PASS / MISSING / UNKNOWN
CREDENTIAL = PASS / MISSING / UNKNOWN
USER_IMAGE_TO_IMAGE_MODEL = PASS / MISSING / UNKNOWN
IMAGE_MODEL_OUTPUT_TO_AGENT = PASS / MISSING / UNKNOWN
STAGE_A_OUTPUT_CAN_FEED_STAGE_B = PASS / MISSING / UNKNOWN
```

全部 PASS → `RUNTIME_CAPABILITIES_DECLARED = PASS`。
任一 MISSING/UNKNOWN → `PRODUCTION_GATE = BLOCKED`。

不得因为 schema 声明支持就直接写 `RUNTIME_CAPABILITIES_VERIFIED = PASS`。

## D. Verified Runtime Profile Check

若私有状态中存在：

```text
RUNTIME_PROFILE_VERIFIED = TRUE
RUNTIME_PROFILE_FINGERPRINT_MATCH = TRUE
```

且 scope 覆盖当前链路：

```text
RUNTIME_CAPABILITIES_VERIFIED = PASS
FIRST_LIVE_VERIFICATION_REQUIRED = FALSE
```

否则：

```text
RUNTIME_CAPABILITIES_VERIFIED = PENDING
FIRST_LIVE_VERIFICATION_REQUIRED = TRUE
```

这不是配置缺失。

## E. Security Check

```text
PRIVATE_PROVIDER_CONFIG_IN_REPO = FALSE
API_KEY_EXPOSED_IN_NORMAL_CHAT = FALSE
RUNTIME_PROFILE_STORED_OUTSIDE_REPO = TRUE
```

## F. Ready Decision

满足 Bootstrap + declared capabilities + production gate 后可：

```text
READY
RUNTIME_STATE = READY_WAITING_FOR_START
RUNTIME_CAPABILITIES_DECLARED = PASS
RUNTIME_CAPABILITIES_VERIFIED = PASS / PENDING
FIRST_LIVE_VERIFICATION_REQUIRED = TRUE / FALSE
```

## G. First Live Verification

若需要首次验证，不额外生成测试图。第一笔真实任务兼任验证。

最终交付前实际确认：

```text
LIVE_VISION_READ = PASS
LIVE_REFERENCE_EDIT = PASS
LIVE_OUTPUT_READBACK = PASS
```

B 任务额外确认 `LIVE_STAGE_A_TO_STAGE_B_PASS_THROUGH = PASS`。

SOURCE_REFERENCE = CURRENT_USER_IMAGE
ASPECT_RATIO = 9:16
OUTPUT_ASPECT_RATIO_EXACT = 9:16
LOCK_TARGETS = EXPLICIT

SURFACE_STATE_MANIFEST = PASS
SOURCE_BROWNING_CHAR_DONENESS = RESOLVED_OR_NA
SOURCE_GLOSS_MOISTURE_LEVEL = RESOLVED_OR_NA
SOURCE_SAUCE_OIL_COVERAGE = RESOLVED_OR_NA
SOURCE_CRUST_SKIN_CRACK_STATE = RESOLVED_OR_NA

```text

```

```text

```

缺任何一项 → 不生成，先修复缺失项。

## I. Post-Generation Fidelity + Hero + Aspect Gate

VISION_MODEL QC 必须明确判断：

```text
FINAL_OUTPUT_ASPECT_RATIO = 9:16
NON_9_16_DELIVERY = FALSE
SURFACE_STATE_DRIFT = FALSE
APPETITE_MUTATION = FALSE
UNSUPPORTED_COMPLETION = FALSE
BACKGROUND_BIG_IDEA = PASS
PRODUCT_DERIVATION_EVIDENCE >= 3
BACKGROUND_ARCHITECTURE_PLAN = PASS
PROP_DEPENDENCY_FOR_PREMIUM_LOOK = FALSE
HERO_SPATIAL_CRITICAL_FAILURE = NONE
GENERIC_DISPLAY_CASE_LOOK = FALSE unless identity-critical
TWO_LAYER_FLATNESS = FALSE
FAKE_L4 = FALSE
MULTI_PRODUCT_INVENTORY_LOOK = FALSE when applicable
```

任何一项失败都不得交付；按 `fidelity-qc.md` / `semantic-qc.md` / `hero-background-architecture.md` / `retry-policy.md` 定向重试。

特别规则：**非严格 9:16 即 Critical Failure，无论画面多好看都不能作为 Stage A PASS。**

## J. Profile Invalidation / Recovery

配置 fingerprint 变化、Credential 失效、读图失败、reference edit 失败、输出不可读、Stage A→B 传递失败时：

```text
RUNTIME_PROFILE_VERIFIED = FALSE
RUNTIME_CAPABILITIES_VERIFIED = PENDING / BLOCKED
RUNTIME_STATE = SETUP_GATE
PRODUCTION_GATE = BLOCKED
```

上下文压缩、版本变化或 P0 规则无法准确复述时也重新 BOOTSTRAP / Pre-flight。
