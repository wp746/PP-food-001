# Targeted Retry Policy

Retry only after diagnosis.

## Rule

```text
FAILED_DIMENSION → TARGETED_RETRY
PASSED_DIMENSIONS → LOCK_AND_PRESERVE
RANDOM_FULL_REGENERATION = FORBIDDEN
MAX_ATTEMPTS_PER_STAGE = 3
```

## A Retry Types
- product identity/geometry drift → tighten Reference Lock;
- vessel/package drift → tighten vessel/package lock;
- surface-state drift → reduce appetite enhancement and re-lock source state;
- wrong aspect → canvas/aspect correction only;
- weak hero → reframe/light/depth without changing product;
- generic background → rebuild only background architecture from current category/product evidence;
- physics mismatch → correct only steam/condensation/liquid/contact realism.

## B Retry Types
- product demotion → enlarge/foreground product, reduce headline aggression;
- wrong category skin → reroute current category and replace skin only;
- flat typography → revise spatial text system only;
- copy/Chinese text error → regenerate or repair text layer while preserving product/background when possible;
- previous-job contamination → reset current job and rebuild compact B contract;
- weak One Big Idea → change campaign concept layer without redesigning product.

If hard gates remain unreliable after 3 attempts, stop and report failure instead of pretending PASS.
