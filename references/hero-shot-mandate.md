# Hero Shot Mandate｜世界级美食英雄定妆照硬规则

本文件是 Stage A 商拍出图的**空间与氛围硬规则**，适用于所有食品品类——面食、米食、汤锅、烧烤、肉食、甜品、烘焙、饮品、生鲜、包装食品，**无一例外**。

与 `semantic-background-rules.md` 的关系：那份文件解决「环境是什么语义」；本文件解决「环境必须达到什么空间与英雄标准」。两者叠加生效，语义正确但空间扁平同样不合格。

---

## 0. 硬规则声明（不可协商）

以下为 Stage A 出图的强制验收条件，任何品类路由、场景模块、摄影模式都不得豁免：

1. **食材 DNA 锁定是第一原则（Priority 0）**。任何背景设计、氛围营造、空间构建、构图策略，一律不得以牺牲食材 DNA 为代价。食材身份、几何、器皿、摆盘、物理关系发生任何漂移——**整张图直接判废，不留补救**。模型自发补足的人物、文字、招牌之所以是污染，正因为他们既抢戏又诱发主体漂移。**先锁死食材，再谈背景。**
2. **高级材质舞台，非真实场所**。背景必须是高级商拍级材质舞台（editorial material stage）：材质（石材 / 陶 / 木 / 金属 / 织物）、色彩基调、光影层次从食材属性与调性推导。**禁止把背景设计成真实经营场所**（面馆、店面、档口、市集、餐厅内景）——真实场所语境会诱发图像模型自发补足人物与文字（实战证实），且与世界级商拍的影棚本质相悖：**世界级美食大片从来是在高级舞台上拍的，不是在店里拍的。**
3. **质感密度与食物身份锚点**。高级舞台必须有足够信息密度：材质层次 + 核心作料围铺 + 器物纵深共同指向这道菜的身份。禁止空旷死寂的棚拍背景板，也禁止无语境的通用影棚。
4. **氛围与食材调性匹配**。温度（冷食冷调 / 热食暖调）、明度（清鲜明亮 / 浓郁深沉）从食物属性推导，不得错配。
5. **世界级英雄定妆照调性**。主体是全场唯一英雄：光池聚焦、轮廓光雕刻边缘、低机位纪念碑感、观者视线被单点锁定。环境永远服务主体，不与之竞争。
6. **工业级商拍质量**。可量产的稳定质量标准：主体锐度顶格、材质可信、光影物理正确、色彩分级商业投放级。不是抽卡式偶发好图，是每一张都达到投放标准。
7. **所有品类强制遵循**。本文件不区分品类豁免。品类只改变「舞台映射」，不改变「空间与英雄标准」。

## 1. 空间舞台四层结构（每次生成必须显式构建）

| 层 | 距离 | 内容 | 虚化梯度 | 作用 |
|---|---|---|---|---|
| L1 前景 | 最近相机 | 台缘、虚化作料散落、器具边缘 | 最重虚化 | 空间入口，制造「在场感」 |
| L2 中景 | 主体所在 | 食物 + 光池（light pool 渐落）| 锐度顶格 | 英雄位，全场唯一焦点 |
| L3 中后景 | 主体后 0.5–1.5m | 失焦高级材质器物：粗陶、木纹、哑光金属 | 中虚化 | 质感纵深 + 身份锚点 |
| L4 远景 | 最深 | 高级暗部纵深：多层柔 bokeh、材质面没入暗处 | 轻-中虚化 | 纵深尽头 + KV 排版留白 |

规则：

- 四层**必须全部存在**，缺层即为平背景，判 Semantic Critical Failure。
- 虚化必须**连续递进**，不允许「主体清晰 + 背后一刀切虚」的两层平面感。
- 主体必须坐在**光池**内：光从主体向外自然衰减，而非均匀照亮整个空间。
- L4 必须为 KV 排版预留干净负空间（Stage B 联动要求）。
- L3 / L4 只允许**材质与器物**（陶器、木纹、石材、金属、织物），不允许场所结构（门、窗、街道、店面、就餐区）。

## 2. 英雄定妆照灯光处理

人像定妆照逻辑迁移到食物：

- **主光**：45° 大面积柔光，按食物温度属性选色温（冷食冷白、热食暖金）。
- **轮廓光**：后侧精准 rim light，勾主体边缘——油亮材质勾高光、半透明材质勾透光、酥脆材质勾边缘锐度。让食物「从空间里被雕刻出来」。
- **接触阴影**：物理正确的软接触阴影 + 器皿表面环境反射，主体绝不悬浮、绝不贴片。
- **分离度**：主体与背景必须有亮度或色温差异，观者视线单点锁定主体。

## 3. 核心作料围铺（Ingredient Dressing）

食物身份锚点的核心手法——把这道菜的**核心作料与器物**铺在台面上当 stage dressing：

```text
前景层（最虚）：散落的主料原形态——干辣椒、花椒、蒜瓣、芝麻、面粉、咖啡豆、抹茶粉……
贴身层（轻虚）：主料加工物——辣子油碗、酱料碟、奶油抹刀、切片剩余、随行配料……
中后层（中虚）：器物与库存——叠碗、竹盘、模具、工具、包装、原料罐……
```

边界（红线，违反即 Fidelity Critical Failure）：

- 作料**只铺盘子外面的台面**（Region C），永不进盘、永不接触食物；
- 不得构成「菜里加了料」的视觉误读；
- 虚化与低对比保证**不喧宾夺主**——它们是舞台布景，不是配角演员；
- 数量克制：每层 2–4 个元素足矣，堆砌即失败。

## 4. 温度对比逻辑

冷食与热食的空间语言必须相反：

| | 冷食（凉皮/冷面/冷饮/生食） | 热食（汤面/火锅/烧烤/现烤） |
|---|---|---|
| 主体光 | 冷白、清透、干净 | 暖金、浓郁、体积感 |
| 环境氛围 | 可暗可亮，但零热气 | 允许克制蒸汽/炭火 |
| 高级手法 | 主体冷净 × 环境暖深的温度对比，凸显「凉」 | 蒸汽逆光 + 炭火余温 + 器物热度 |
| 禁止 | 任何热气、烟雾 | 冷食级清透打光 |

## 5. 品类高级舞台映射（速查表，非穷举）

舞台材质、色彩与光性从食物属性推导，**映射的是材质语言，不是场所**。完整品类方法论（材质舞台 / 前景围铺 / 食欲感渲染 / DNA 锁定要点 / 温度与光）见 `cuisine-style-map.md`，本表仅作速查：

| 品类 | 舞台材质基调 | 色彩与光性 | 身份锚点（作料/器物围铺） | 食欲信号（第一语言） |
|---|---|---|---|---|
| 面食/米食（凉皮/蒸面/拌面） | 深色岩板/玄武岩台面 + 哑光粗陶 | 暖主光 + 深色纵深，冷食用冷白主光 | 生面、面粉、辣子油碗、蒜瓣、黄瓜 | 面条油润挂汁、红油镜面、配菜水灵 |
| 汤面/热食 | 深色哑光石材 + 陶器 | 暖金体积光 + 克制蒸汽 | 汤勺、葱花碟、原料罐 | 汤面浮油镜面、面条湿润、热气逆光 |
| 蛋糕/甜品 | 奶油白大理石 + 细腻织物 | 高调柔光 + 粉彩点缀 | 奶油抹刀、糖粉、原料碟 | 奶油缎面光泽、慕斯镜面、切面湿润 |
| 饮品 | 玻璃/金属反光台面 + 冰感材质 | 冷调高光 + 通透 | 原料果、冰块、杯具层 | 冰块通透、冷凝水珠、分层清晰 |
| 红油麻辣 | 哑光深色石材（抑制环境反光污染） | 单点暖光突出红油高光 | 干辣椒、花椒、辣子油碗 | 红油镜面透亮发光、辣椒油润 |
| 烧烤 | 铸铁/粗粝石板 + 炭色哑光 | 暗调 + 边缘光勾焦脆感 | 竹签、炭纹、干料碟 | 焦糖化油亮、油滴微滴、孜然可见 |
| 清鲜/日料 | 浅色石材/桧木 + 极简留白 | 冷白柔光 + 通透 | 板前器物、酱油碟、山葵 | 刺身半透明、鱼肉湿润反光、米粒油亮 |
| 生鲜/水果 | 湿润石面 + 水雾语境 | 高饱和冷光 | 藤筐、水珠、柠檬角 | 水珠凝结、切面水分光泽 |
| 火锅/江湖菜 | 铸铁 + 粗陶 + 黄铜细节 | 暖金体积光 + 逆光蒸汽 | 生鲜菜品、干料碟、竹签 | 沸点微泡、毛肚水润挺括、麻酱挂壁 |
| 西式牛排 | 深色石板 + 铸铁 + 哑光碳黑 | 暖主光 + 焦壳高光 | 海盐碟、整蒜、胡椒研磨 | 焦壳油亮 × 切面粉嫩多汁对比 |
| 咖啡/烘焙 | 原木 + 水泥灰 + 陶 + 哑光黄铜 | 柔和自然光感 | 咖啡豆、亚麻布、原料罐 | 奶泡缎面、crema 琥珀反光、脆壳光泽 |
| 包装食品 | 中性高级台面 + 包装阵列（保留源图货架语境） | 均匀商拍光 | 同类产品阵列、原包装 | 印刷质感锐利、货架新鲜感 |

映射为**材质方向**而非布景清单；置信度不足时降级到品类级材质（见 `dish-semantic-router.md`），但**空间四层与英雄标准不得降级**。

## 6. 与 Region Edit Budget 的关系

- 四层空间、作料围铺全部发生在 **Region C（Environment，高预算区）**；
- 主光/轮廓光作用于主体但只改变照明渲染，不改几何（Region A 锁定不动）；
- 本文件**不授权**任何主体改动——空间感再好，食物漂移仍然失败（回到 Priority 0）。

## 7. QC 验收（并入 semantic-qc.md 执行）

生成前自检：

1. 遮住主体，环境的材质、色彩、作料是否仍指向这道菜的身份（而非某个场所）？
2. 四层景深是否齐全？虚化是否连续递进？
3. 主体是否坐在光池内、被轮廓光雕刻、与背景有分离度？
4. 食物是否被渲染出「想吃」的食欲信号（见 §8）？

生成后验收：

```text
Hero Spatial Score >= 85 才通过
Appetite Score >= 85 才通过
```

Critical Failure（任一即重试，重试方向见下）：

- **食材 DNA 漂移（最高级失败）**：主体身份/几何/器皿/摆盘发生改变 → 废图重做，加强 DNA 硬锁首段；
- 平背景 / 两层平面感 / 背景板 → 重试方向：重建四层空间结构；
- 舞台材质与食物调性无关（换成任何菜都通用）→ 重试方向：按品类舞台映射重选材质；
- 作料围铺抢了主体 → 重试方向：加大虚化、降低对比、减少元素；
- 温度错配（冷食冒热气等）→ 重试方向：按温度对比表重设灯光；
- 食欲感缺失（干涩、发暗、无光泽）→ 重试方向：按 §8 重写食欲渲染指令；
- **画面出现真实场所结构**（门头/招牌/街道/店内就餐区/窗户门框）→ 重试方向：prompt 移除一切场所语义，只保留材质语言；
- **画面出现文字 / 人物** → 重试方向：见 §9 强负面清单。

## 8. 食欲感渲染（Appetite Rendering）——氛围感的真正来源

商业美食片的「氛围感」不来自场所叙事，来自**食物本身被光线激发的食欲信号**。每张图必须渲染以下食欲语言（以源图已有属性为限，不发明不存在的属性）：

- **油脂光泽**：红油镜面反光、烤物油亮表皮、酱汁挂壁——**高光是食欲的第一语言**；
- **湿润度**：汤汁浸润、水珠鲜脆、酱料包裹感——干涩的食物没有食欲；
- **脆度与微距质感**：芝麻粒、辣椒碎、蒜末、糖霜在浅景深内清晰可辨；
- **温度可视化**：热食克制蒸汽逆光 / 冷食冷凝水珠——温度必须是可读的；
- **色彩饱和管理**：红油的红必须透亮发光不发死；绿叶必须鲜活不灰败；
- **「刚做好」状态**：面条油润挂汁、配菜挺立水灵——像刚从厨房端出来的下一秒。

验收问句：**这张图能否让观者在 3 秒内产生「想吃」的生理反应？** 不能 → Appetite Score 不过。

各品类的具体食欲信号清单（红油的镜面透亮 / 甜品的奶油缎面 / 日料的刺身半透明 / 饮品的冰块通透……）见 `cuisine-style-map.md` 对应品类的「食欲感渲染」条目——**出图 prompt 的 APPETITE RENDERING 段必须从该条目取材**，不得只写通用套话。

## 9. Stage A 强负面清单（图像模型自由发挥风险镇压）

本节是针对 `gpt-image-2`（以及同类「真实性补足型」图像生成模型）的**实战经验沉淀**。模型面对「真实场所」语境的本能行为会自动补足画面：补招牌字、补顾客人物、补品牌 logo、补菜单。

**V5.3.0 起，背景规则已整体转向高级材质舞台（§0.2），真实场所语境被从源头移除**——模型补人补字的触发条件大幅减少。强负面清单从「主防线」降级为「兜底保险」，继续默认携带。

### 9.1 强负面前置清单（写入每个 prompt 的最后一节）

每次 Stage A 出图 prompt 必须显式包含以下强负面词条：

```text
ABSOLUTELY NO TEXT ANYWHERE IN THE FRAME:
NO signboards, NO signage, NO storefront letters, NO menu boards,
NO price tags, NO paper labels, NO handwritten notes,
NO Chinese characters, NO Latin letters, NO numbers,
NO logos, NO watermarks, NO brand marks,
NO text on wall, NO text on decoration, NO text on packaging,
NO text on lamp shades, NO text on plates, NO text on banners.

ABSOLUTELY NO HUMAN PRESENCE ANYWHERE IN THE FRAME:
NO chef, NO cook, NO customer, NO pedestrian, NO human figures,
NO human face, NO head, NO arm, NO hand, NO fingers,
NO silhouette, NO partial body, NO shadow of a person,
NO mannequins, NO dummies, NO humanoid statues.

NO REAL VENUE STRUCTURE:
NO storefront, NO restaurant interior, NO street, NO doors, NO windows,
NO dining area, NO counter service scene.

THE FRAME MUST BE TOTALLY FREE OF HUMAN PRESENCE, TEXTUAL CONTENT AND REAL VENUE STRUCTURE.
```

### 9.2 历史经验：构图策略性规避（特殊场景参考）

V5.2.x 时代（真实场所语境）的实战结论，留作特殊场景参考——若用户明确要求带环境叙事的构图：

| 触发场景 | 模型倾向 | 构图规避策略 |
|---|---|---|
| 「门头面馆」 | 加招牌字、加行人 | 镜头不指向门头，镜头水平扫向对面墙，墙是收边不出现门 |
| 「早市街头」 | 加顾客、加文字招牌 | 改用「露台/屋檐下」单一视角，背景收边为墙+檐 |
| 「档口明档」 | 加厨师半身像、加菜单立牌 | 改为「托盘特写」——背景只出现木质托盘+无字纸 |
| 「食堂餐桌」 | 加抢镜顾客 | 镜头贴近桌面俯拍，只看桌面与盘子 |

本质：**让镜头画面里没有"门"、"街道"、"人物可能存在"的空间**。V5.3.0 的正解是从 prompt 里彻底不出现场所语义。

### 9.3 兜底：生成后第一道检验

生成后第一步不是看构图，是过这两道硬闸：

```text
1. 用 OCR 思路扫整张图：有任何可见文字吗？有 → 重生成。
2. 检视远景失焦区：有人形/人影/人肩/人手吗？有 → 重生成。
3. 检视背景：有场所结构（门/窗/街道/店内）吗？有 → 重生成。
```

OCR 检查在模型驱动下可做（宿主多模态或 `mcp__image_gen__read_image` 同类），最终以用户人眼验收为准（宿主无视觉时不得宣称 QC 通过）。

## 10. 一句话标准

> **先锁死食材，再搭高级舞台——观众一眼记住的必须是那道被光雕刻、让人流口水的菜。**
