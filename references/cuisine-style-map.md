# Cuisine & Flavor Style Map

本文件把菜系、风味、温度、食材气质映射到**材质舞台、前景围铺、食欲感渲染、DNA 锁定要点、色彩和摄影语言**。

它不是固定模板库，而是**语义设计参考**。系统必须结合源图、用户菜名、实际场景和主体材质做二次判断。

**V5.4.0 全品类方法论对齐**：每个品类都按已验证的 v4 定稿方法论（安康蒸面）组织——先锁 DNA，再搭高级材质舞台，四层景深配核心作料围铺，食欲感渲染是氛围的唯一来源。五个维度缺一不可。

## 总原则

1. 用户明确菜名优先。
2. 菜系只决定视觉倾向，不得改变食物本体。
3. 不要用地域刻板符号堆砌背景。
4. 道具必须弱化、失焦、服务主体。
5. 不得把"高级"简单等同于暗色木桌和暖琥珀灯。
6. 色彩首先保护食物真实颜色，再做环境配色。
7. **（V5.3.0）背景一律为高级材质舞台语言（石材/陶/木/金属/织物），禁止场所叙事**——不出现餐厅/门店/街头/堂食等场所词；场所语境会诱发图像模型自发补足人物与文字。
8. **（V5.4.0）食欲感渲染是每个品类的必填项**——出图 prompt 必须携带该品类的食欲信号指令；「背景对、光对、但食物不好吃」仍判废。
9. **（V5.4.0）DNA 锁定要点是每个品类的漂移高发区清单**——写 DNA Lock 段时必须对照本品类要点逐项锁死。

## 川味鲜麻 / 青花椒 / 藤椒

**风味关键词**：鲜麻、清辣、酸香、开胃、热汤、青花椒香。

**材质舞台**：深灰哑光石板台面 + 深釉粗陶器物 + 克制黄铜细节，远景暖深暗部 bokeh。

**前景围铺（身份锚点）**：青花椒枝、少量干辣椒、酸菜小陶罐、小料碟——盘外台面，重虚化。

**食欲感渲染**：热汤表面镜面反光；花椒油珠在汤面悬浮发亮；鱼片边缘微卷挺立、湿润水灵；酸菜爽脆有汁感；青椒翠挺；克制逆光热气。汤色清黄透亮，绝不能浑。

**DNA 锁定要点**：鱼片厚度与摆法、花椒分布位置、汤色必须清黄（不转红）、酸菜量与位置、器皿形态。

**温度与光**：热食——暖金主光 + 汤面高光 + 克制蒸汽；藤椒绿是画面呼吸色。

**配色**：藤椒绿、酸菜黄绿、汤汁暖金、深灰、暖铜光。

**摄影**：CINEMATIC_EDITORIAL；强广告需求时可 DRAMATIC_FOOD_CAMPAIGN。

**避免**：纯红辣背景、满画面干辣椒、通用黑木桌+黄灯模板、赛博绿霓虹、汤色转红（DNA 漂移）。

## 川味红油 / 麻辣

**风味关键词**：麻辣、红油、强刺激、热烈。

**材质舞台**：哑光黑石台面 + 深木纹器物（抑制环境反光污染红油高光）。

**前景围铺（身份锚点）**：干辣椒堆、花椒粒、辣子油碗、整瓣蒜。

**食欲感渲染**：**红油镜面光泽是全图第一食欲语言**——红必须透亮发光、从内部透光，绝不发死发浑；辣椒段油润饱满；肉片油亮挂汁；蒜泥湿润。单点暖光伺候红油高光。

**DNA 锁定要点**：红油厚度与覆盖范围、辣椒段位置与数量、主料形态与切法、红油红度（不许加深或减淡）。

**温度与光**：热食——单点暖光突出红油反光锥；环境暗部收得深。

**配色**：辣椒红、红油深红、暖黑、少量金色。

**摄影**：DRAMATIC_FOOD_CAMPAIGN。

**避免**：让所有红油食品变成同一个火锅广告模板；红油发暗发死（Appetite Fail）。

## 粤菜 / 清鲜中餐

**风味关键词**：清鲜、细腻、原味、克制、通透。

**材质舞台**：浅灰细磨石材台面 + 白瓷哑光器物 + 浅木细节，高调柔光，纵深干净。

**前景围铺（身份锚点）**：蒸鱼豉油碟、叠放白瓷碗、竹蒸笼（器物方向，克制数量）。

**食欲感渲染**：蒸鱼豉油汁水清亮挂鱼身；鱼肉湿润反光、肌理分明；葱丝挺立水灵；鸡皮油润光泽完整；汤体清透见底。清鲜类的食欲=「嫩与润」，不是「辣与亮」。

**DNA 锁定要点**：蒸鱼完整性（鱼鳍鱼尾形态）、葱丝姜丝位置与量、鸡皮完整度、汤料分布、白瓷器皿形制。

**温度与光**：热食为主——明亮柔光、通透干净，允许极克制蒸汽。

**配色**：中性白、淡木色、低饱和绿色、柔暖白光。

**摄影**：NATURAL_EDITORIAL 或 CINEMATIC_EDITORIAL（明亮型）。

**避免**：重烟、深黑、过度戏剧化、强行加辣油色（DNA 漂移）。

## 湘味 / 香辣家常

**风味关键词**：香辣、锅气、鲜香、家常热烈。

**材质舞台**：质感木纹台面 + 黑石细节 + 暗铜器物，暖色环境光。

**前景围铺（身份锚点）**：干辣椒、豆豉碟、蒜瓣、青蒜段。

**食欲感渲染**：锅气光泽（食材表面油亮带镬气感）；辣椒油润挂汁；肉片油亮；青蒜鲜活挺立；汤汁浓亮挂勺。

**DNA 锁定要点**：辣椒比例与种类（青/红/干）、腊肉或主料形态、汤汁量。

**温度与光**：热食——暖主光 + 食材油光高光。

**配色**：辣椒红、青椒绿、暖木、深灰。

**摄影**：CINEMATIC_EDITORIAL。

**避免**：与川味红油混同（湘味重香辣不重麻）、过度烟熏。

## 西北 / 北方主食 / 面食（含凉皮/蒸面/拌面）

**风味关键词**：扎实、热乎、主食感、饱腹、质朴。

**材质舞台**：玄武岩/深色石板台面 + 哑光粗陶 + 胡桃木纹，远景高级暗部纵深。

**前景围铺（身份锚点）**：生面条、面粉、辣子油碗、蒜瓣、黄瓜条——**已验证的 v4 定稿组合**。

**食欲感渲染**：面条油润挂汁、每根面条湿润高光；红油镜面光泽透亮；配菜（豆芽/黄瓜丝）挺立水灵带细水珠；面皮表面光泽连贯。「刚拌好/刚出锅一秒」状态是硬要求。

**DNA 锁定要点**：面条宽度/厚度/切形/折叠堆叠方式、辣油分布与颜色、配菜种类与位置、酱汁池位置、器皿形制与花色——**v4 验证：这是 DNA 漂移最高发品类，逐项显式锁死**。

**温度与光**：拌面/凉皮=冷食冷白主光零蒸汽 × 环境暖深（温度对比）；汤面=暖金光 + 克制蒸汽。

**配色**：麦色、汤色、肉色、暖木、深棕。

**摄影**：CINEMATIC_EDITORIAL。

**避免**：过度豪华、过度暗黑、改面条形态（宽度/折叠）、增删配菜。

## 江湖菜 / 火锅 / 干锅

**风味关键词**：聚餐、锅气、热烈、江湖感。

**材质舞台**：铸铁器物 + 粗陶 + 深木 + 黄铜细节，深色哑光台面，暖金 bokeh 层。

**前景围铺（身份锚点）**：生鲜菜品（鲜毛肚/黄喉/青菜挺括）、干料碟、竹签。

**食欲感渲染**：锅底红油沸点微泡（刚沸腾的活性状态）；食材油亮；毛肚黄喉水润挺括；克制蒸汽逆光；麻酱挂壁。沸腾感与蒸汽=「正在进行时」的食欲。

**DNA 锁定要点**：锅型（九宫格/鸳鸯/铜锅/砂锅不可互换）、菜品摆放位置与数量、汤底红度与油层厚度、生熟状态。

**温度与光**：热食——暖金体积光 + 逆光蒸汽 + 炭火余温感。

**配色**：深红、铜、黑、暖金。

**摄影**：DRAMATIC_FOOD_CAMPAIGN。

**避免**：换锅型（DNA 漂移）、蒸汽过量成灾、菜品重新摆位。

## 日料 / 寿司 / 刺身

**风味关键词**：清洁、极简、精致、冷静、新鲜。

**材质舞台**：桧木/浅色石材台面 + 极简留白 + 哑光和纸质感纵深。

**前景围铺（身份锚点）**：山葵块、酱油碟、姜片、木质料理器物（刃物只暗示不入画主体）。

**食欲感渲染**：刺身**半透明质感**（光穿透鱼肉边缘）；鱼肉肌理湿润反光；醋米颗粒分明带油亮光泽；酱油清亮。日料的食欲=「鲜与透」，靠 rim light 勾出鱼肉半透明边缘。

**DNA 锁定要点**：寿司形态/数量/摆法、鱼片覆盖方式与厚度、配位（山葵/姜片位置）、器皿（漆器/木板/白瓷不可互换）。

**温度与光**：冷食——冷白柔光 + 通透感 + 零热气。

**配色**：中性色、食材本色、柔和木色。

**摄影**：NATURAL_EDITORIAL。

**避免**：大量樱花/武士/霓虹等无关符号、寿司数量与摆法变化（DNA 漂移）。

## 韩式烤肉 / 韩餐

**风味关键词**：烤制、聚餐、香气、现代。

**材质舞台**：铸铁烤盘 + 哑光不锈钢 + 黑石台面，现代光源。

**前景围铺（身份锚点）**：生肉片、生菜叶、酱料碟、烤夹（器物方向）。

**食欲感渲染**：肉面焦糖化光泽（深棕亮壳）；油脂微滴反光；生菜水灵挺括；酱料挂壁。

**DNA 锁定要点**：肉片形态与大小、包饭配菜组合与位置、烤盘类型。

**温度与光**：热食——暖光 + 烤盘热度感 + 克制烟气。

**配色**：食物本色、金属灰、暖灯、少量绿色配菜色。

**摄影**：CINEMATIC_EDITORIAL 或 DRAMATIC_FOOD_CAMPAIGN。

**避免**：换配菜组合（泡菜碟/生菜/蒜片位置是 DNA）、过度西式牛排化。

## 西式牛排 / 烤肉

**风味关键词**：焦香、肉汁、精致、结构感。

**材质舞台**：深色石板 + 铸铁器皿 + 哑光碳黑金属，暗调高级纵深。

**前景围铺（身份锚点）**：海盐碟、整颗蒜、黑胡椒研磨器、（仅源图有时）迷迭香。

**食欲感渲染**：焦壳（crust）油亮光泽与切面粉嫩多汁的**对比**；肉汁清亮汇聚在切面；黄油融化光泽；焦壳棱线锐利。牛排的食欲=「焦壳的脆与切面的嫩」同框可读。

**DNA 锁定要点**：熟度切面颜色（一分都不能变）、配菜摆位、肉的厚度与形状、酱汁位置。

**温度与光**：热食——暖主光 + 焦壳高光 + 极克制烟气。

**配色**：深棕、肉色、绿色点缀、暖中性色。

**摄影**：CINEMATIC_EDITORIAL。

**避免**：熟度漂移（DNA 高发）、擅自加配菜（芦笋/番茄/香草只按源图）。

## 海鲜 / 清鲜鱼类

**风味关键词**：鲜、水润、清洁、细致。

**材质舞台**：湿润浅色石材台面 + 冰感材质 + 白瓷/哑光银器细节。

**前景围铺（身份锚点）**：柠檬角、冰块、海盐碟、藤筐。

**食欲感渲染**：表面湿润水光（湿润=鲜的第一信号）；鱼肉反光；柠檬角水珠；冷凝水珠（冷食类）；贝类汁水。禁俗套海洋背景——高级感来自「湿与冷」的材质语言。

**DNA 锁定要点**：鱼种形态（不可换鱼）、摆盘方向、贝壳开合状态、配柠檬/冰的位置。

**温度与光**：清鲜冷调 + 高显色白光；冰镇类必须冷凝水珠。

**配色**：食材真实颜色、中性灰、低饱和青绿。

**摄影**：NATURAL_EDITORIAL 或 CINEMATIC_EDITORIAL。

**避免**：俗套海浪/沙滩/蓝色海洋海报背景、鱼种漂移。

## 烧烤 / 炭火烤制

**风味关键词**：烟火气、炭火、即时性、暗调浓香。

**材质舞台**：炭色铸铁 + 粗粝石板 + 哑光黑，暖灯 bokeh 远景。

**前景围铺（身份锚点）**：孜然罐、辣椒面碟、竹签、干料碟。

**食欲感渲染**：焦糖化边缘油亮；孜然辣椒面附着可见（微距质感）；油滴微滴反光；竹签木质纹理清晰；炭火暖光打在肉面上。烧烤的食欲=「焦与油」的可读层次。

**DNA 锁定要点**：串型与签子数量、肉块大小与密度、焦化程度（不加深）、配辣椒面/芝麻的分布。

**温度与光**：热食——暗调 + 边缘光勾焦脆 + 炭火反光 + 克制轻烟。

**配色**：暖灯、炭火红、深背景、食物本色。

**摄影**：DRAMATIC_FOOD_CAMPAIGN。

**避免**：街头/夜市场景结构（场所污染）、烟雾过量、烤串数量变化。

## 咖啡 / 烘焙

**风味关键词**：香气、松弛、Lifestyle、现代、日常高级感。

**材质舞台**：现代原木 + 水泥灰材质 + 陶器 + 哑光黄铜细节，柔和自然光感。

**前景围铺（身份锚点）**：咖啡豆散落、亚麻布、原料罐、（器物方向）手冲壶。

**食欲感渲染**：奶泡绵密缎面光泽；咖啡油脂（crema）琥珀色反光；面包表皮脆壳光泽 + 内瓤湿润组织；黄油湿润融化感；克制蒸汽逆光。

**DNA 锁定要点**：杯型与容量、拉花图案形态（一比一）、奶咖分层比例、面包造型与割包纹路。

**温度与光**：热饮暖光 + 克制蒸汽 / 冰咖冷调 + 冷凝水珠（按源图温度）。

**配色**：咖啡棕、奶油色、自然木、环境中性色。

**摄影**：NATURAL_EDITORIAL。

**避免**：拉花图案漂移（DNA 高发）、改变奶咖比例、俗套蒸汽喷发。

## 蛋糕 / 甜品

**风味关键词**：柔和、细腻、轻盈、精致。

**材质舞台**：奶油白大理石台面 + 柔和织物 + 淡色陶器，高调柔光。

**前景围铺（身份锚点）**：糖粉、奶油抹刀、原料碟（按源图甜品成分）。

**食欲感渲染**：奶油**缎面光泽**（不是哑光死白）；慕斯镜面反光；水果水珠与鲜活光泽；切面层次湿润清晰（蛋糕胚/夹心/奶油三层可读）。甜品的食欲=「绵密与湿润」的质地暗示。

**DNA 锁定要点**：裱花形态与数量、切面层次结构、顶部装饰排布、水果种类与位置、盘/托器皿。

**温度与光**：冷甜点冷白柔光 / 温热甜品暖光（熔岩类），零热气（冷甜品）。

**配色**：由甜品本身颜色主导——奶白、草莓红、巧克力棕、抹茶绿。

**摄影**：NATURAL_EDITORIAL。

**避免**：自动加花/金箔/莓果/糖粉（DNA 污染——只按源图）、裱花重排。

---

## 水果 / 沙拉 / 轻食

**风味关键词**：新鲜、清爽、健康、自然。

**材质舞台**：明亮浅色石材台面 + 藤编/玻璃器物，清新通透光感。

**前景围铺（身份锚点）**：同源水果散落、薄荷叶（仅源图有时）、原料碗碟。

**食欲感渲染**：水珠凝结（新鲜第一信号）；切面水分光泽；叶子挺立；酱汁挂壁；脆度可见（苹果切面的光边）。轻食食欲=「水灵与脆」。

**DNA 锁定要点**：果种（不可换）、切法与切面、排列组合、酱汁分布、叶菜种类。

**温度与光**：冷食——明亮冷调高显色光，水珠必须物理可信。

**配色**：以食材本色为主，背景低饱和。

**摄影**：NATURAL_EDITORIAL。

**避免**：加不属于源图的水果/酱料、过度水雾喷洒。

---

## 冰饮 / 奶茶 / 果茶

**风味关键词**：清凉、通透、年轻、Lifestyle。

**材质舞台**：玻璃/金属反光台面 + 冰感材质纵深（哑光金属 + 玻璃器物层），冷调高光。

**前景围铺（身份锚点）**：原料果、冰块、杯具层、（器物方向）搅拌勺。

**食欲感渲染**：**冰块通透感与冷凝水珠是第一食欲语言**；奶盖绵密光泽；珍珠油润饱满；分层清晰界面干净；杯壁水雾物理可信。饮品的食欲=「冰与透」。

**DNA 锁定要点**：分层结构与各层比例、杯型与容量、吸管形态、配料（珍珠/果肉/奶盖）数量与位置、颜色配比。

**温度与光**：冷饮——冷调高光 + 通透 + 冷凝水珠，**任何热气都是 Critical Failure**。

**配色**：饮品与品牌源图颜色优先，环境辅助。

**摄影**：NATURAL_EDITORIAL 或 CINEMATIC_EDITORIAL。

**避免**：不合逻辑蒸汽、分层比例漂移（DNA 高发）、换杯型。

---

## 包装食品 / 零售商品

**风味关键词**：商品清晰、货架秩序、零售商业感。

**材质舞台**：**特殊品类——保留源图自带货架/柜台语境**（RETAIL_SHELF 模块），只优化灯光、排列与主体分离；不把商品移到通用餐桌棚拍。

**前景围铺（身份锚点）**：同类产品阵列、原包装陈列、层进深。

**食欲感渲染**：包装材质印刷质感清晰锐利；光泽控制（哑光处哑光、亮膜处亮膜）；产品排列整齐有秩序感。零售的食欲=「货架新鲜感与产品质感」。

**DNA 锁定要点**：包装印刷图案一比一（禁重写）、包装结构与材质、陈列数量与位置、价签/标签位置。

**温度与光**：均匀商拍光 + 反射控制。

**配色**：包装主色主导。

**摄影**：RETAIL commercial treatment。

**避免**：重写包装、改 Logo、擅自拆包装摆盘、移出货架。

# 组合规则

实际菜品经常跨多个维度，例如：

> 青花椒酸菜鱼 = 川味鲜麻 + 热汤 + 鱼类 + 高级暗调材质舞台

此时：

- 菜品语义：SICHUAN_FRESH_PEPPER
- 材质模块：SEAFOOD + HOT_SOUP
- 场景模块：TABLETOP（材质舞台）——仅当源图自带可保留语境时才考虑 RESTAURANT/STREET_FOOD 受限模块
- 摄影模式：CINEMATIC_EDITORIAL 或克制的 DRAMATIC_FOOD_CAMPAIGN
- 食欲渲染：取川味鲜麻（汤面镜面+花椒油珠+鱼片水润）× 海鲜（湿润反光）的并集，剔除与源图属性冲突项

组合时**食欲感渲染取并集、材质舞台取主调、DNA 锁定取全并集**——跨品类菜的 DNA 锚点只会更多，不会更少。

不要因为加载"鱼类"就使用海洋风背景，也不要因为加载"热汤"就统一暗木暖灯。
