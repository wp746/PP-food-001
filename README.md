# PP-food-001

一个可复用的智能体 Skill，用于把用户提供的真实美食随手拍升级为高级商业摄影 / 电影级美食摄影，同时尽可能保持原始食物、食材几何、摆盘、器皿、包装和真实物理关系不变。

当前版本：**V5.0.0**

## V5 核心升级

V5 不再只解决“高保真商拍”，还新增了**菜品语义驱动背景设计**。

核心原则：

> **保留产品本身，升级摄影品质；根据具体菜品语义设计环境。**

也就是：

- 主体在物理上高保真；
- 背景、色彩、道具、光线和氛围根据菜名、菜系、风味、温度、烹饪方式和实际场景来设计；
- 不再把所有热食统一做成深木桌 + 暖琥珀灯 + 陶罐 + 蒸汽的模板。

## 适用场景

当满足以下情况时，使用本 Skill：

- 美食主体清晰可识别；
- 用户希望获得影棚级 / 商业广告级效果；
- 原始食材、几何形态、摆盘、器皿、包装、手持关系、货架 / 展示关系等必须高度忠于源图；
- 原图可能来自桌面、手持、货架、展示柜、街边摊位、咖啡馆、餐厅或其他真实美食场景；
- 用户可能明确告诉菜名，也可能只上传一张图什么都不说。

本 Skill 不绑定单一图像模型，适用于基于源图进行图像编辑的工作流，包括 GPT Image 2。

## 信息优先级

如果用户明确提供：

- 菜名
- 菜系
- 风味
- 主要卖点
- 想要的氛围

这些信息优先用于**背景语义设计**。

如果用户没有提供菜名，系统会先内部推断菜品语义并根据置信度选择：

- 具体菜品级背景；
- 品类级背景；
- 保守通用但仍与食品类型相关的商业环境。

自动猜菜只用于决定背景和摄影语言，不能用来改变食材。

## 高保真目标

以下数值是通过视觉不变量和 QC 实现的**感知验收目标**，并非严格像素相似度：

- 食物身份保真度：**≥95%**
- 食材几何保真度：**≥95%**
- 器皿 / 容器身份保真度：**≥98%**
- 摆盘保真度：**≥95%**
- 物理关系保真度：**≥95%**
- 商业摄影质量评分：**≥85/100**
- 菜品语义背景评分：**≥85/100**

## V5 的三个验收维度

最终必须同时满足：

### 1. HIGH FIDELITY

仍然是源图中的同一份具体食物，而不是 AI 重新做了一份类似的菜。

### 2. HIGH PHOTOGRAPHY UPGRADE

灯光、材质、景深、背景、构图和调色明显从随手拍提升到商业摄影级。

### 3. HIGH SEMANTIC RELEVANCE

背景与具体菜品有关。

例如用户明确告诉系统“青花椒酸菜鱼”，则背景应围绕：

- 鲜麻
- 青花椒 / 藤椒
- 酸香
- 川味
- 热汤
- 高级川味餐饮环境

来设计，而不是继续使用与普通汤面完全相同的通用背景。

## 运行流程

1. 读取 `SKILL.md`。
2. 读取用户是否明确提供菜名、菜系、风味或卖点。
3. 根据源图建立 `Fidelity Manifest`，先锁定主体。
4. 如果用户未提供菜名，使用 `dish-semantic-router.md` 内部推断菜品语义与置信度。
5. 只加载与当前食物相关的 `food module`。
6. 只选择一个主要 `scene module`。
7. 根据 `cuisine-style-map.md` 和 `semantic-background-rules.md` 生成菜品专属背景方向。
8. 选择合适的摄影模式：`NATURAL_EDITORIAL`、`CINEMATIC_EDITORIAL` 或 `DRAMATIC_FOOD_CAMPAIGN`。
9. 使用 `references/execution-template.md` 组装最终图像编辑指令。
10. 执行图像生成 / 编辑。
11. 使用 `references/fidelity-qc.md` 检查主体保真和商业摄影质量。
12. 使用 `references/semantic-qc.md` 检查背景是否真正与菜品语义匹配。
13. 如未通过，按具体失败类型定向重试，而不是随机重新生成。

不要在每次任务中加载全部模块。过多约束同时进入生成阶段，反而可能降低稳定性。

## V5 的反模板规则

系统不得默认所有热食都采用：

- 深色木桌；
- 暖琥珀灯；
- 陶罐；
- 大量 bokeh；
- 黑金餐厅；
- 夸张蒸汽。

电影级商业摄影不是一种固定颜色，而是：

- 有目的的灯光；
- 与食物材质匹配的光线；
- 受控色彩；
- 真实材质；
- 清晰视觉层级；
- 与具体菜品语义一致的环境设计。

## 核心工作逻辑

这套 Skill 的目标不是：

> “把食物重新生成得更漂亮。”

而是：

> **让同一份真实食物，看起来像被世界级商业摄影团队在一个真正属于这道菜的环境中重新布光、重新布景、重新拍摄。**

最终唯一正确目标：

> **同一份食物 + 同一个器皿 + 同样主要食材和结构 + 菜品专属背景语义 + 商业广告级摄影。**
